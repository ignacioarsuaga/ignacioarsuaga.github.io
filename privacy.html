Privacy policy

Last updated: 23 November 2026

Home Monitor is a personal home-monitoring tool run by Ignacio Arsuaga for one household. It is used only by that household.

What it accesses

With the household's permission through Google sign-in, Home Monitor reads device status from the household's own Google Home account, such as the list of devices and whether each one is online. It reads device status only. It does not control devices, change settings, or access cameras, audio, or any other Google data.

How the data is used

Device status is used only to produce a private health check for the same household.

Sharing and retention

The data is not shared with anyone and is not sold. It is not stored beyond the session in which it is read.

Revoking access

Access can be revoked at any time from the Google Account's third-party connections page.
